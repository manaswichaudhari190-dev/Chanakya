Architecture & Data Provenance

Core design principles and proof invariants defined in the CHANAKYA v7.13 Reconciled Specification.

Core Invariants

  • Hard Invariant: No proof, no actionable recommendation.
  • ETOG: Evidence-Typed Ontology Graph for relationship validation.
  • NCS: Normative Closure Scoring to ensure requirement completeness.
  • MSSS: Minimal Sufficient Standard Set to prevent tender inflation.
  • Temporal Gate: Automatically rejects withdrawn or superseded editions.
